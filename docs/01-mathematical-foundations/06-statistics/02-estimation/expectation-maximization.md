# Expectation-Maximization

## TL;DR

**Expectation-Maximization (EM)** is an iterative algorithm for estimating model parameters when a problem contains **latent or missing variables**.

It alternates between:

1. **Expectation (E-step):** estimate the latent variables.
2. **Maximization (M-step):** update the model parameters using these estimates.

The process is repeated until convergence.

---

## Idea

Suppose we observe data $X$, but there are hidden variables $Z$ that we do not observe.

We want to estimate model parameters $\theta$:

$$
\theta^* = \arg\max_\theta P(X \mid \theta)
$$

This can be difficult because the latent variables are unknown.

EM solves this by alternating between estimating $Z$ and updating $\theta$.

---

## E-Step

Using the current parameters $\theta$, calculate the expected values or probabilities of the latent variables:

$$
P(Z \mid X,\theta)
$$

These values describe how likely each latent state is for each observation.

For example, in a Gaussian Mixture Model, the E-step calculates the probability that each data point belongs to each Gaussian component.

---

## M-Step

Using the estimates from the E-step, update the model parameters:

$$
\theta
\leftarrow
\arg\max_\theta
\mathbb{E}*{Z\mid X,\theta*{\text{old}}}
\left[
\log P(X,Z\mid\theta)
\right]
$$

The updated parameters are then used in the next E-step.

---

## Algorithm

```text
Initialize parameters θ

        │
        ▼
     E-Step
Estimate latent variables
        │
        ▼
     M-Step
Update model parameters
        │
        ▼
    Converged?
      /     \
    No       Yes
    │         │
    └─────────┘
       Stop
```

In pseudocode:

```text
initialize θ

repeat:
    E-step:
        estimate latent variables given θ

    M-step:
        estimate θ given the latent variables

until convergence
```

---

## Example: Gaussian Mixture Models

Consider a dataset generated by several Gaussian distributions.

The cluster assignment of each point is unknown.

The **E-step** calculates:

$$
P(z_i=k\mid x_i)
$$

which is the probability that point $x_i$ belongs to Gaussian component $k$.

The **M-step** then updates:

* the component means $\mu_k$
* the covariance matrices $\Sigma_k$
* the mixture weights $\pi_k$

These two steps are repeated until the parameters stabilize.

---

## Convergence

EM generally increases the likelihood of the observed data at every iteration:

$$
P(X\mid\theta_{t+1})
\geq
P(X\mid\theta_t)
$$

The algorithm stops when the change in the likelihood or parameters becomes sufficiently small.

EM can converge to a **local optimum**, so different initializations can produce different solutions.

---

## Applications

EM is commonly used for:

* Gaussian Mixture Models
* Missing-data problems
* Latent-variable models
* Clustering
* Hidden Markov Models
* Parameter estimation
* Image and speech processing

---

## Limitations

* Can converge to a local optimum.
* May require many iterations.
* Can be sensitive to initialization.
* Each iteration can be computationally expensive.
* The choice of model still has to be appropriate for the data.
