# Gaussian Mixture Models

## TL;DR

A **Gaussian Mixture Model (GMM)** represents a probability distribution as a weighted combination of multiple Gaussian distributions.

It is commonly used for **clustering**, **density estimation**, and modeling data with multiple underlying groups.

---

## Definition

A GMM assumes that the data is generated by a mixture of $K$ Gaussian distributions:

$$
p(x)
=

\sum_{k=1}^{K}
\pi_k \mathcal{N}(x \mid \mu_k, \Sigma_k)
$$

where:

* $K$ is the number of components
* $\pi_k$ is the weight of component $k$
* $\mu_k$ is its mean
* $\Sigma_k$ is its covariance matrix
* $\mathcal{N}$ is a Gaussian distribution

The mixture weights satisfy:

$$
\pi_k \geq 0
$$

and

$$
\sum_{k=1}^{K}\pi_k=1
$$

---

## Intuition

Instead of assuming that all data comes from one Gaussian distribution, a GMM assumes that it comes from several Gaussian distributions.

For example, data might look like:

```text
       Gaussian 1       Gaussian 2

          ● ●●             ●●
        ● ●● ●           ● ●●
       ●● ● ●             ●● ●
```

Each Gaussian can represent a different **cluster** or subpopulation.

Unlike methods such as $k$-means, GMMs provide **probabilistic cluster assignments**.

---

## Soft Clustering

For a data point $x$, a GMM can calculate the probability that it belongs to component $k$:

$$
P(z=k\mid x)
$$

This is called the **responsibility** of component $k$ for $x$.

A point can therefore belong to multiple clusters with different probabilities:

```text
Point x

Cluster 1: 0.80
Cluster 2: 0.15
Cluster 3: 0.05
```

This is known as **soft clustering**.

---

## Training

GMMs are commonly fitted using the **Expectation-Maximization (EM)** algorithm.

### 1. Initialize

Choose initial values for:

* $\mu_k$
* $\Sigma_k$
* $\pi_k$

### 2. Expectation Step

Calculate the responsibility of each component for each data point:

$$
\gamma_{ik}
===========

P(z_i=k\mid x_i)
$$

### 3. Maximization Step

Update the parameters using the calculated responsibilities.

### 4. Repeat

Repeat the E-step and M-step until convergence.

---

## GMM vs. K-Means

| Property      | K-Means               | GMM                      |
| ------------- | --------------------- | ------------------------ |
| Clustering    | Hard                  | Soft                     |
| Cluster shape | Spherical             | Elliptical               |
| Probabilities | No                    | Yes                      |
| Model         | Distance-based        | Probabilistic            |
| Training      | Centroid optimization | Expectation-Maximization |

GMMs are more flexible because each component can have its own covariance structure.

---

## Applications

Common applications include:

* **Clustering**
* **Density estimation**
* **Anomaly detection**
* **Speech recognition**
* **Image segmentation**
* **Pattern recognition**
* **Generative modeling**

For anomaly detection, points with very low estimated probability density can be considered potential anomalies.

---

## Limitations

GMMs have several limitations:

* The number of components $K$ usually has to be chosen.
* EM can converge to a local optimum.
* Results can depend on initialization.
* Gaussian components may be inappropriate for complex distributions.
* High-dimensional covariance matrices can be expensive to estimate.
