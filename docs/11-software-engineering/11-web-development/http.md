# HTTP

## HTTP Requests

| Method | Purpose                      |
| ------ | ---------------------------- |
| GET    | Retrieve data                |
| POST   | Create or process data       |
| PUT    | Replace an existing resource |
| PATCH  | Update parts of a resource   |
| DELETE | Remove data                  |


## HTTP Status Codes

| Code | Meaning      |
| ---- | ------------ |
| 200  | Success      |
| 201  | Created      |
| 400  | Bad request  |
| 401  | Unauthorized |
| 403  | Forbidden    |
| 404  | Not found    |
| 500  | Server error |
